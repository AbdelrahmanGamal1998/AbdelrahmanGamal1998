## What I do

- **UI and API automation.** Frameworks in Playwright, Selenium, SHAFT Engine and TestNG, with the Page Object Model and Allure reports, run in GitHub Actions.
- **Quality gates.** API automation that validates every build in the CI/CD pipeline, driven by AI.
- **Performance testing.** JMeter load scenarios simulating up to 8,000 users, and analysis of what breaks first.
- **Security testing.** Automated identity and access management (Keycloak) checks that cut regression time by up to 80%.
- **AI-assisted testing.** A multi-agent Claude Code framework that generates tests and self-heals broken UI and API tests.
- **Traceability and roadmap.** Requirement traceability, coverage measurement (90% of end-to-end tests automated) and the automation roadmap against product specs.
- **Mentoring.** 25 junior testers coached so far, including Headway program trainees.

**Now.** Senior Test Automation Engineer at Pulse by Solutions (Giza Systems), Riyadh, since July 2023.
