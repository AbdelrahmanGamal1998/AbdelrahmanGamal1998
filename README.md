- Build UI and API automation with **Playwright, Selenium, SHAFT Engine and TestNG**, using the Page Object Model and
  Allure reports, integrated into **GitHub Actions**.
- Design **JMeter** load scenarios (up to 8,000 simulated users) and analyze performance bottlenecks.
- Automate **security testing** of identity and access management (Keycloak) and cut regression time by up to 80%.
- Measure requirement traceability and automation coverage (90% of end-to-end tests automated) and plan the
  automation roadmap.
- Engineer a multi-agent **Claude Code** framework for AI-assisted test generation and self-healing.
- Mentor junior testers (25 so far, including Headway program trainees).
